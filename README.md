# AI Difficult Font and Distorted Character Recognition

A CNN-based digit recognition demonstration with rotation, noise, blur and low-contrast distortions.

Upload `model.weights.h5`, exported from the trained CNN in the original Colab notebook.
The app recreates the original CNN architecture and loads its weights; it does not retrain.
